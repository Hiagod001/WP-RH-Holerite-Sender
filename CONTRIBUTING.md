# Contributing

Obrigado por considerar contribuir com o WP RH Holerite Sender.

## Como Contribuir

1. Crie uma branch a partir da `main`.
2. Faca uma alteracao pequena e bem descrita.
3. Execute `npm audit`.
4. Teste o fluxo principal no painel.
5. Abra um pull request com resumo claro.

## Padroes

- Nao suba PDFs reais, relatorios, sessoes ou dados pessoais.
- Mantenha a interface simples para uso operacional do RH.
- Prefira mensagens e erros claros em portugues.
- Evite dependencias novas sem necessidade.

## Checklist

- [ ] Nao inclui dados sensiveis.
- [ ] Testei cadastro de colaborador.
- [ ] Testei conferencia de holerites.
- [ ] Revisei o comportamento de envio.
